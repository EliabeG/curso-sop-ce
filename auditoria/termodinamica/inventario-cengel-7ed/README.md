# Comparação de equações com Çengel e Boles, 7ª edição

Este inventário parcial acompanha a leitura do PDF da edição fornecida para o projeto e a comparação com as páginas de Termodinâmica do curso. A numeração é uma referência para localizar as relações no livro; os arquivos não reproduzem o livro e não constituem uma lista exaustiva de expressões, equações não numeradas, figuras, tabelas, exemplos e exercícios.

Cada registro distingue o que foi localizado ou é equivalente do que continua sem verificação suficiente. Uma relação equivalente depende das hipóteses indicadas; busca textual sem resultado não prova ausência. Rótulos extraídos por OCR podem incluir referências ou apresentar lacunas, de modo que a lista de candidatos e as contagens não demonstram cobertura percentual. Os diagnósticos são revisões automatizadas parciais, não certificação científica, e a continuidade requer confronto visual individual com a edição e verificação da expressão, das hipóteses e da âncora efetiva no curso.

Para continuar: examinar primeiro as linhas não verificadas, confrontar o PDF visualmente, procurar a relação e as hipóteses em todo o E1, registrar evidência de presença/equivalência ou acrescentar conteúdo original e reavaliar independentemente os cálculos.
